\# Shipping Calculator



A command-line Python tool that calculates shipping costs based on package weight and service type.



\## Features

\- Loops to process multiple packages in one session

\- Standard and Express pricing

\- Rejects invalid (zero or negative) weights

\- Surcharge for packages over 20 kg



\## How to run

python shipping\_label.py

\- if/elif/else logic

\- Input validation

\- String formatting with f-strings
